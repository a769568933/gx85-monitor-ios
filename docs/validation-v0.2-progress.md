# GX85 Monitor 0.2 验证进度

日期：2026-10-15。本文记录未完成的开发状态，不是发布说明。

## 已完成的开发步骤

- 协议层新增未知/缺失状态、录像状态、菜单原始参数值、嵌套菜单、错误 XML、正文大小、外部实体、控制指令及输入边界验证。先观察缺失接口的云端失败，再实现到 38 个核心测试通过。
- 拍摄协调新增单次快门和释放、AF/MF 分支、状态确认录像、互斥事务及后台/断连保护；不把 `ok` 当成照片已经保存。
- 参数回读新增 `settingvalue` 属性和文本回复解析，修复测试先出现的原始值丢失问题。
- 居中布局已通过实际 UI 渲染回归：竖屏/横屏、4:3/16:9 四组，提示前后画面中心与大小不变。参数选项采用相机菜单原值，写入后读回确认。
- 点按对焦通过实际模拟器交互测试，画面点按发出请求，控件和黑边不穿透。对焦框为黄色，不冒充已合焦。
- 相册已实现有界 SOAP/DIDL 解析、原件区分、40 项分页、最多三个图片请求、32 MiB 缓存和回放恢复。旧关闭回调不会关闭新相册；录制未知时不强制切模式。
- 最近完成的云端验证：[运行 38672231344](https://github.com/a769568933/gx85-monitor-ios/actions/runs/38672231344)，47 个核心测试、57 个 iPhone 单元测试和 3 个实际 UI 测试通过，设备构建通过。此为开发中的检查点，尚非完整 0.2 发布。
- 原件下载采用 URLSessionDownloadTask 文件方式，逐项处理、限制 8 GiB、同相机跳转与空间预检；取消、断网、大小不符、只有缩略图等测试已通过。本地文件视频播放器在关闭/后台时释放文件。
- 添加照片库权限及文件导出已通过：[运行 38674211524](https://github.com/a769568933/gx85-monitor-ios/actions/runs/38674211524)。Photos 拒绝/受限、系统保存失败、部分成功、文件选择取消和保存中文件保留均有测试。最终截图、整合审查和交付仍在进行。

## 夹具来源

新增菜单夹具使用公开 Lumix 协议研究中的 `menuset`、嵌套菜单及 `cmd_mode/cmd_type/cmd_value` 属性，属于手写的合成输入，不是从用户 GX85 抓取的菜单回复。光圈协议值 `392/256` 与显示值 F1.7 分别保存；不将协议分数当作实际光圈。标签和禁用状态仍须在实机菜单回复上复核。

未获得可验证的 GX85 UDP 元数据签名/版本及实机夹具，因此没有按猜测偏移读取物理拨盘模式。目前手动选择照片/视频操作，通过 getstate.rec 同步已确认的正在录制状态；物理拨盘自动识别待实机验证。
